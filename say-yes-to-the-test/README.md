# 💍 Say Yes to the Test!

**STAT 342 | Statistics Presentation Project**

Welcome to Kleinfeld Bridal, where every bridal dilemma is a statistical conundrum! Inspired by *Say Yes to the Dress*, this project turns hypothesis testing concepts into a fictional bridal-shop storyline featuring Randy, wedding dress prices, and statistically significant drama.

### What We Covered
- **One-Sample Z-Test:** Testing whether the average wedding dress price exceeds $3,000
- **One-Sample T-Test:** Repeating the price analysis using a sample standard deviation
- **Paired T-Test:** Testing whether alterations increase dress prices
- **Chi-Square Test:** Evaluating a claim about the variance in designer dress prices
- **Two-Sample Tests:** Exploring how to compare the means of two populations

### Skills & Concepts
- Statistical inference and hypothesis testing
- Test statistics, p-values, and significance levels
- Confidence intervals
- Z, t, and chi-square distributions
- Applying statistical methods to real-world-style scenarios
