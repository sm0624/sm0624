# 🌎 Climate Machine Learning: Emulating Atmospheric Chemistry

Using machine learning to model natural variability in atmospheric hydroxyl (OH), a key chemical species in the methane cycle.

## 📌 Overview

As a Climate ML Research Intern at the University of Washington, I am developing machine learning models to emulate atmospheric chemistry-climate simulations. My research focuses on capturing natural variability in hydroxyl (OH) beyond seasonal cycles and El Niño–Southern Oscillation (ENSO), with applications to understanding methane variability.

## 🛠️ Methods & Technologies

- 🐍 **Data Analysis:** Python, Pandas, NumPy, Xarray
- 🤖 **Machine Learning:** PyTorch, scikit-learn, autoencoders
- 📊 **Statistical Methods:** Principal Component Analysis (PCA), Empirical Orthogonal Functions (EOFs), anomaly analysis
- 🖥️ **High-Performance Computing:** UW Hermes, Linux, SLURM

## 📊 Current Progress

- Processed **156M+ data points** from over **1,000 years** of climate simulation data.
- Developed autoencoder models to compress and reconstruct global OH spatial patterns.
- Experimented with latent dimensions, neural network architectures, activation functions, and training hyperparameters to improve reconstruction performance.
- Achieved a validation \(R^2\) of approximately **0.82** in preliminary experiments, with up to **52× data compression**.
- Evaluating model performance using reconstruction error, validation metrics, and spatial patterns.

## 🔬 Research Goals

The ongoing goal is to develop a reliable, computationally efficient emulator that captures meaningful variability in atmospheric OH. This work explores how machine learning can represent complex climate chemistry simulations while reducing data dimensionality.

## 🚧 Project Status

**In progress** — continuing model experiments, hyperparameter tuning, and evaluation of reconstruction performance.
