# 📊 Statistical Analysis of Policing Experiences

## 📌 Overview
Conducted exploratory data analysis (EDA) on 1,600+ survey responses to examine Black women's experiences and perspectives when seeking police assistance. Explored patterns in reported police interactions and differences across demographic groups.

Completed through the **Statistics Directed Reading Program at the University of Washington**.

## 🛠️ Tools & Methods
- **Languages & Libraries:** Python, Pandas, NumPy
- **Methods:** Data cleaning, exploratory data analysis (EDA), demographic analysis, statistical analysis, and data visualization

## 📈 Key Finding
Found a 32% higher rate of reported violent police threats among non-U.S.-born respondents in the analysis.
