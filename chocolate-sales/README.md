# 🍫 Chocolate Sales Regression

📊 Analyzing factors influencing chocolate sales using **R and statistical modeling**.

## 🎯 Project Overview
Analyzed 3,013 global chocolate sales transactions from 2022–2024 to investigate how product type, country, year, and boxes shipped relate to sales revenue.

## 🛠️ Methods & Tools
- **Language:** R
- **Libraries:** tidyverse, ggplot2
- Exploratory Data Analysis (EDA)
- Multiple Linear Regression
- Stepwise Model Selection (AIC)
- Interaction Effects & ANOVA
- Regression Diagnostics

## 💡 Key Findings
- 📈 Average transaction revenue increased from approximately $5,652 in 2022 to $6,366 in 2024.
- 🍫 Product and year were selected by all three stepwise regression methods.
- 🔗 Interaction effects revealed relationships between product, country, and shipment size.
